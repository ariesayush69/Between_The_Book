# Between The Covers 📚

**Between The Covers** is a peer-to-peer pre-loved book sharing platform designed to connect book lovers, enable easy book exchanges, and promote sustainable reading within communities.

🌐 **Live Demo:** [between-the-cover.netlify.app](https://between-the-cover.netlify.app/)

---

## ✨ Key Features

- 📖 **Discover & Browse:** Search and discover pre-loved books listed by readers nearby.
- 🤝 **Peer-to-Peer Sharing:** Connect directly with fellow readers to exchange or borrow books.
- ⚡ **Seamless Web Experience:** Fast, responsive, and intuitive interface built for readers.
- 🌐 **Instant Web Access:** Fully deployed and live on Netlify.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (React / Web Framework)
- **Backend / Database:** Supabase
- **Hosting & Deployment:** Netlify
